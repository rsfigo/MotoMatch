# Entscheidungen

Hier steht, welche Annahmen und Entscheidungen beim Bau von MotoMatch getroffen wurden – und warum.
Neue Einträge kommen jeweils unter den passenden Meilenstein.

## Offen: vor dem Livegang prüfen

- [ ] **Führerausweis-Grenzwerte** (A1, A beschränkt, Drosselung) gegen die aktuellen Angaben der Strassenverkehrsämter bzw. der VZV prüfen. Die Werte stehen als Konstanten in `src/lib/licence.ts`.
- [ ] **Impressum und Datenschutz** mit echten Angaben füllen (aktuell Platzhalter).
- [ ] **Daten mit `dataStatus: "needsVerification"`** nachprüfen (siehe `npm run validate:data`, das die Anzahl ausgibt).

## M0 – Setup

| Thema            | Entscheidung                                                                                                           | Begründung                                                                                                                                                                                                          |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| TypeScript       | Version **6.0** statt 7.0                                                                                              | TypeScript 7 (der neue native Compiler) wird von `typescript-eslint` noch nicht unterstützt (`<6.1.0`). Wechsel, sobald es geht.                                                                                    |
| Linting          | ESLint 10 mit `typescript-eslint` (type-checked), React-Hooks- und React-Refresh-Regeln, Prettier                      | `eslint-plugin-jsx-a11y` unterstützt ESLint 10 noch nicht. Statt Installations-Tricks (`--legacy-peer-deps`) verzichten wir vorerst darauf; Barrierefreiheit wird manuell und mit Lighthouse geprüft.               |
| Routing          | React Router 8 im **deklarativen Modus** (`<BrowserRouter>`, `<Routes>`)                                               | Seitenübergänge mit `AnimatePresence` brauchen die alte Seite während des Ausblendens. Im deklarativen Modus behält sie ihre eigene `location`; mit Data-Routern verschwinden Loader-Daten der alten Route zu früh. |
| Seitenübergänge  | `AnimatePresence mode="wait"`: alte Seite blendet aus (150 ms), neue gleitet ein (300 ms)                              | Ruhig und gut lesbar. Scrollposition wird bei «Zurück» wiederhergestellt (`useScrollMemory`).                                                                                                                       |
| Code-Splitting   | Jede Seite per `React.lazy`, Skeleton als Fallback                                                                     | Kleiner Start-Download, kein Spinner.                                                                                                                                                                               |
| Theme            | Dunkel ist **Standard, unabhängig vom System**; Wahl in `localStorage` (`motomatch-theme`)                             | So im Briefing gewünscht. Ein Inline-Skript in `index.html` setzt das Theme vor dem ersten Rendern (kein Aufblitzen).                                                                                               |
| Theme-Wechsel    | Kreisförmige Enthüllung über die View Transitions API, sonst sofortiger Wechsel                                        | Moderner Effekt ohne Zusatzbibliothek; bei reduzierter Bewegung oder fehlender Unterstützung einfach ohne Animation.                                                                                                |
| Farben           | Tokens als CSS-Variablen (`src/styles/tokens.css`), Tailwind-Klassen zeigen darauf (`bg-surface`, `text-ink-muted`, …) | Ein Ort für alle Farben; das helle Theme überschreibt nur Werte.                                                                                                                                                    |
| Kontrast         | Orange als Fläche mit **dunkler** Schrift; orange Schrift im hellen Theme dunkler (`#C2410C`)                          | Weiss auf `#FF5A1F` hat nur 3.1:1 (zu wenig für WCAG AA). Dunkel auf Orange hat 6.3:1.                                                                                                                              |
| Schriften        | Inter Variable (Oberfläche), Space Grotesk Variable (Headlines), selbst gehostet via Fontsource                        | Kein Google-Fonts-CDN. Beide Schriften haben `tabular-nums`.                                                                                                                                                        |
| Animationen      | Nur `transform` und `opacity`; Hover-Farbwechsel ohne Übergang; Lichteffekte als Verläufe statt `blur()`               | Performance auf dem Handy (60 fps). `MotionConfig reducedMotion="user"` lässt bei reduzierter Bewegung nur Fades übrig.                                                                                             |
| Seitentitel/Meta | Hook `usePageMeta` setzt Titel, Beschreibung und OG-Tags                                                               | React 19 kann `<title>` selbst in den `<head>` hängen, würde aber die Grundwerte aus `index.html` (für Crawler ohne JS) doppeln.                                                                                    |
| Zeilenenden      | `.gitattributes` erzwingt LF                                                                                           | Damit Prettier unter Windows und macOS gleich formatiert.                                                                                                                                                           |
| Import-Alias     | `@/…` zeigt auf `src/`                                                                                                 | Kürzere, stabile Importe (`@/lib/format` statt `../../lib/format`).                                                                                                                                                 |
